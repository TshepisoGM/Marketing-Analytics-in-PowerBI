# Marketing-Analytics-in-PowerBI
This project presents an interactive Marketing Analytics Dashboard built in Power BI to evaluate and optimize campaign performance across multiple channels. It transforms raw marketing data into clear, actionable insights to support data-driven decision-making and improve return on investment (ROI).

The dashboard tracks key performance indicators (KPIs) such as  conversion rates. It enables users to compare performance across channels (e.g., social media), analyze trends over time, and identify high- and low-performing products.

The workflow includes data cleaning and preprocessing in Excel, data extraction and transformation using SQL, and data modeling and visualization in Power BI. Relationships between datasets were established, and DAX measures were created to calculate key metrics and enhance analytical depth.

Key features of the dashboard include:

Interactive filters and slicers for campaign,reviews, and time period
Dynamic visualizations for trend and performance analysis
KPI summary cards for quick insights
Comparative analysis across marketing channels

This project provides a centralized and user-friendly view of marketing performance, enabling stakeholders to monitor campaigns in real time, optimize budget allocation, and improve overall marketing strategy
